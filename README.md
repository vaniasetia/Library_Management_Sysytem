Create a Library System using FastAPI with 2 entities
1. Books: You can add or remove books using API calls
2. Users: You can create or delete users using API calls
Each book has Title, Genre, Last Issued Time, Last Return Time
Each user has Name, User ID, Books issued (list of books)
You need to add API calls for users to issue and return books
and when a user browses through catalogue of books (using an API calls), they can see only available books (non-issued)
